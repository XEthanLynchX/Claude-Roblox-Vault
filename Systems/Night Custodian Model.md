# Night Custodian model (Blender)

Built 2026-10-19 from the concept sheet `models/reference/night_custodian_concept.png`. Blender is back in use for this one model; Claude Design is still the default for 2D design work.

## Files (project `models/` folder)
- `NightCustodian.blend`: the source scene (Blender 5.2). Collections: NightCustodian > Body / Clothes / Props / Rig, plus Reference (the concept sheet as a hidden image empty).
- `NightCustodian.fbx`: the **Roblox-ready** export: rig + 4 game meshes (NC_Head, NC_Skin, NC_Suit, NC_Gear) + all 4 animations, textures embedded.
- `textures/`: 1024px PBR maps for Roblox SurfaceAppearance (`NC_<part>_Color/Normal/Roughness.png`, plus `NC_Head_Emissive.png` for the glowing eyes). `textures/2048/` holds the full-res bakes.
- `reference/nc_preview_*.png`: viewport previews of each animation; `nc_preview_sheet.png` shows all four.

## Model
- ~2.34 m tall (2.42 m with the cap), emaciated, long arms, hunched.
- Source parts (collections Body/Clothes, hidden): CustodianBody, CustodianHead (skull face, deep sockets, nasal cavity, gaping grin with lip ridges), Teeth (crowded, uneven, some missing), Eyes (red glow), Cap, Jumpsuit, Boots, Spikes, Claws, NamePatch ("AGNES"). **Mop removed (2026-10-19 late evening).**
- The build is scripted: text blocks `nc_joints` (joint positions), `nc_build_body/head/cap/clothes/props/materials`. Edit the numbers and re-run to regenerate. `CustodianBody_SkinSource` (hidden) is the editable skin-modifier skeleton for the body.
- Realistic materials (script `nc_materials_v2`): veined, bruised, cracked skin with pores; grime from AO; dried + wet blood layers; raw flesh at the back wound; fabric weave; scuffed leather; bone spikes. Masks are a vertex colour "Mask" (R blood, G dark cavity, B raw flesh).
- These are baked into image textures (script `nc_bake`, Cycles on the RX 7800 XT) for Roblox.

## Game meshes (collection NC_Export, built by `nc_export_build`)
| Mesh | Contains | Tris |
|---|---|---|
| NC_Head | head (subdiv 1, decimated), teeth, eyes | ~16k |
| NC_Skin | body, spikes, claws | ~10k |
| NC_Suit | jumpsuit, name patch + text | ~17k |
| NC_Gear | boots, cap | ~13.5k |
- Each is under Roblox's 20k-tri MeshPart limit and has one material, so one SurfaceAppearance each. Roblox PBR maps max out at 1024px, which is why the model is split into 4 texture sets.
- Normal maps are OpenGL tangent space (what Roblox needs). Metalness is 0 everywhere, so no metalness map.
- Fixed: a fingertip was fused to the thigh by the skin modifier, which stretched in crawls; those faces were removed and hand weights cleaned.

## Rig
- `NightCustodianRig`, 54 bones: Root, Pelvis, Spine1, Spine2, Chest, UpperChest, Neck, Head; per side Clavicle, UpperArm, Forearm, Hand, 4 fingers × 3, Thumb × 3, Thigh, Shin, Foot, Toe.
- Body is auto-weighted; jumpsuit, boots, spikes and claws got weights copied from the body. Head pieces and the cap follow the Head bone; the patch follows Chest; the Mop follows Hand.R.

## Animations (30 fps, in place, loop: last frame = first)
| Action | Frames | Notes |
|---|---|---|
| NC_Walk | 1–37 | Hunched, dangling arms, head twitch |
| NC_Run | 1–23 | Low sprint, wide arm swing |
| NC_Crawl | 1–49 | On all fours, diagonal gait, splayed elbows, head craned forward |
| NC_CrawlRun | 1–21 | Bounding gallop, spine flexes |
- Generated by scripts `nc_anim_lib`, `nc_anim_walk`, `nc_anim_rest` (FK keys from a scripted 2-bone IK). Tweak the numbers and re-run to re-bake.

## Known gaps / next steps
- The grabber tool from the concept isn't modelled yet.
- To use in Roblox: import `NightCustodian.fbx` with the 3D Importer (rig + animations). Add a SurfaceAppearance to each MeshPart with its Color/Normal/Roughness maps (+ Emissive on NC_Head). Publish the 4 animations, then swap the Closer (currently rigid parts animated in code; see [[Design/The Closer]]).
- Re-doing the textures: edit `nc_materials_v2`, re-run it, then run `nc_bake` for each group and downscale to 1024.

## In the game (2026-10-20)
- Imported as ServerStorage.Closer from `models/NightCustodian_Roblox.fbx` (no animation in that file). Animations come from `models/NightCustodian_anim.json` -> `tools/export_closer_anims.py` -> `src/shared/CloserAnims.luau`. To change an animation: edit in Blender, re-run the JSON export snippet (see Log), run the tool, sync. See [[Design/The Closer]].
